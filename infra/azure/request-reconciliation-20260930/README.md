基础设施 `infra/azure/apps.bicep` 为主服务显式开启 `ERROR_LOG_ENABLED=true`。运行时只增加这一项环境变量，镜像保持 `sha256:ddcf307081e515e80d01fc89529e98ef011632768f7d7dcf87a7ee3dfb420550`，没有改 Token 结算、价格、重试或客户历史余额。未启用 DEBUG 或 Azure 请求/响应正文诊断。

该开关启用现有错误记录功能：每个失败 attempt 写 type=5，包括 model/channel、错误码、状态、耗时、本地/上游 request ID；无上游响应头的连接失败仍可能没有上游 ID。错误日志原有代码也保存用户/Token 的标识名称和脱敏错误消息，依现有权限访问；本次脱敏导出和 GitHub 留痕只保留汇总元数据。错误记录 token/quota=0 表示没有成功结算，**不能当作 Azure 实际成本为 0**。

候选修订 `ca-anyrouters-web--audit-errors-20260930` 的三类受控请求通过：
- 上游 invalid_value：HTTP 400，type=5，保存 Azure request ID，额度不变。
- 正常 Responses：HTTP 200，输入 8、输出 5，quota=115；符合现有价格和 default 折扣。
- 流式主动断开：上游先返回 HTTP 200，客户端 curl 超时，type=5/client_abort/499，保存 Azure request ID，额度未增加。

Bicep 编译通过。候选仅改变环境变量的完整模板比较通过。新修订已从 0% 独立验证、1% 小流量升至 100%，正式 API 再次验证上游拒绝留痕和正常计费通过。首页默认 Python UA 返回 Cloudflare 403，浏览器 UA 与新旧修订源站均返回 200，未修改边缘防护。完整结果见 verification.json。
