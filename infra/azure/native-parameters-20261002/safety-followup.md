# 维护与额度复核（2026-10-02）

初次发布后的扩展审查发现了以下边界缺口，并以实际转换代码的失败测试复现。先将生产流量回退到 `ca-anyrouters-web--audit-errors-20260930`，再修复和重新验收；不调整价格、折扣、余额或历史消费。

## 补充修复

- Responses 流式回答先输出文字、随后输出函数调用时，旧处理器跳过函数调用。本次同时保留文字与工具增量，正常工具完成为 `tool_calls`，截断仍为 `length`；完成事件不重复拼接参数，用量保持上游原值。
- Chat→Responses 转换器不支持旧 `functions/function_call` 返回契约。现在在上游请求前明确返回 400、禁止重试，提示使用 `tools/tool_choice` 和带 `tool_call_id` 的工具结果；旧 `role=function` 历史同样提前拒绝。此项是明确的兼容边界，不宣称自动支持所有旧客户端。
- 新采样规范只影响已核实的当前型号。原生 Responses 与 Chat→Responses 保留旧 GPT 型号原有采样行为；直接 Chat 仍保留自己的历史规则，避免扩大改动范围。
- Responses 新增 effort 别名遵循可选字段指针约定，显式空字符串返回 400，缺省保持缺省。

## 回归与计费验收

新增失败回归覆盖真实出站请求、零上游调用、旧模型零值保留、流式文字与工具共存、截断及参数不重复。Go 全仓回归和相关包 race 检查必须通过后才构建。

回退前追加的正式域名检查验证：三种无效请求在异步退款后，独立测试令牌的 `remain_quota` 和 `used_quota` 与请求前完全一致，没有消费日志；每次错误只有一个渠道尝试。Luna/Terra 现代工具调用及结果回传共四次成功，额度差额、日志总额与实际用量一致。测试令牌额度仅 100000，低于信任预扣旁路门槛；验证包含实际预扣/退款路径，不只检查 HTTP 状态。

最终候选、正式版本和重新验收结果将在本文件追加。公开证据仅人工构造的请求摘要；私有日志不含凭据，客户原始提示词不进入仓库。

## 后续维护规则

新增模型须逐项确认原生接口、推理和采样能力，再加入当前型号能力判断及对应回归；不能按名字相似盲目扩大参数删除范围。新增协议转换必须覆盖普通回答、流式文字加工具、工具结果续传、失败禁止重试和额度返还。保持统一结算入口，不在适配器额外扣费或修改历史消费。

发布沿用 ACR 镜像、零流量候选验证、1% 到 100% 流量切换。回退只切换应用版本，不回滚账单；保留旧镜像、流量记录与配置快照。
