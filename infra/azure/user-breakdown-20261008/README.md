# 用户消费构成统计发布记录

## 功能与入口

- 管理员：用量明细点击用户 → 用户信息 → 查看模型与渠道占比。
- 同一面板新增简版和详细版切换；简版按当前渠道类型合并来源，多个 Azure 渠道合并，已删除或未知渠道保留为其他，详细版保留逐模型和渠道查询。
- 原入口：用户列表 → 操作菜单 → 月度消费；可切换月度账单、模型、渠道视图。
- 默认选择上一个完整北京时间自然月（当前月核算上月）；1 月自动切到上一年 12 月。其他年份、月份仍可手动选择，当前月标为截至目前。
- 金额为该账号全部 API Keys 的历史网站扣费，退款、净消费分列；不是充值现金或实际云厂商账单。
- 扣费占比 = 所选周期内本分组扣费 / 全部扣费，退款前。百分比独立四舍五入两位；无扣费分母时显示破折号。
- 月/年总额、模型分组、渠道分组来自同一有界年度聚合，各维度分别加总，不交叉相加。模型取历史日志名字；空模型、已删除渠道仍保留。
- CSV 带账号、周期、截止时间、精确金额、占比及分母；空周期导出保留明确的 empty_period 行。

## 变更范围与兼容

只扩展管理员只读统计接口与 UI，不迁移数据库、不修改余额或扣费链。保留管理员鉴权、查询限流、15 秒超时、独立日志数据库与 no-store；金额使用 decimal 和十进制字符串。旧接口响应缺少模型分组时，新 UI 给出刷新提示，不导出误导性空表。

全站收入与 Azure/GCP 真实云成本对账不是本次功能。日志清理会影响历史报告覆盖范围，重要月份应保存导出快照。
