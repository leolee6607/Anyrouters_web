# 用户月度网站消费发布交接（2026-10-08）

## 行为与口径

管理员在用户列表的操作菜单中打开“月度消费”，查看该用户所有 API Key 的月度扣费、退款、净消费和渠道明细，可切换年份并导出 CSV。自然月采用北京时间，当前月截止到查询时刻；同一响应固定 as_of，CSV 带上时间与口径。

金额按历史消费/退款日志中的 quota 汇总，不按当前价格重算。网站消费金额不等于现金收入、云平台账单或付款结算。计数称“消费记录数”，包含异步补扣日志。无记录月份提示现存日志范围，不承诺已删除日志的完整性。已删除渠道保留渠道编号。

只读接口 GET /api/user/:id/monthly-usage?year=YYYY 使用现有管理员鉴权与搜索限流；额外检查管理员身份、用户/年份合法性，查询 15 秒超时。日志查询走 LOG_DB，账号与渠道走 DB。no-store 与关闭弹窗立即清理查询缓存，避免旧数据与管理员报表长时间留存。

int64 汇总并检查溢出、负历史金额；decimal 生成精确金额字符串；前端格式化和 CSV 不经过浮点数金额计算。CSV 处理公式注入。不增加表或迁移，不写入余额，不修改现有扣费和退款链。
