# API 接入说明更新

在密钥页面顶部显示两个可复制的地址，并提供教程入口。教程默认打开「API 接入」，按协议区分 OpenAI Base URL 与 Gemini REST 前缀，附环境变量、鉴权、完整请求路径及错误检查说明。电脑和小屏页面均可使用。

统一使用 `https://api.anyrouters.com` 作为平台网关。模型详情示例同步改用该域名；Gemini 的 Python、JavaScript、TypeScript 示例显式向平台发送 HTTP 请求并带上 `x-goog-api-key`，避免未配置地址的 SDK 默认请求 Google。cURL 使用请求头传 Key，修正单引号内环境变量不展开的问题。Claude 教程移除必须保持代理连接的旧说明，并明确已保存代理需要单独检查。

只修改前端界面、文案与生成的示例。未修改路由、模型配置、鉴权、计费、防火墙或安装脚本。

## 验证

- Default 前端 typecheck、变更文件 ESLint / Prettier、生产构建通过。
- 现有教程回归测试 12 项通过；更新其中已失效的强制代理文案断言。
- 浏览器以模拟普通用户检查：地址复制、教程导航、Key 列表滚动及 1440、1024、390、360 像素视口；六种语言新增文案齐全。
- 复制出的 Python 示例语法有效；cURL 在隔离命令环境中核验请求地址、展开的鉴权请求头及 JSON 内容。
- 发布前已用短期、限模型、限额的平台测试 Key 验证 GPT Responses，以及 Gemini 的 OpenAI 兼容与 Gemini 格式生成，均返回 200 和有效内容。测试 Key 已撤销；该验证不代表每个模型均支持所有接口。
