# 用户月度消费

最新用户要求：在管理员用户列表中，点某个用户即可看其每月网站消费。确认 Taku 的金额是其账号名下的历史实际扣费。先交付该入口，全站收入/云账单对账仍是独立后续范围，不把消费额混作现金收入或云成本。

- 用户列表操作菜单进入月度消费，清楚标识用户编号、显示名、用户名；按年列自然月，当前月截至查询时间，固定北京时间。
- 从 LOG_DB 历史消费(type=2)与退款(type=6)日志汇总：扣费、退款、净消费、调用次数，展开每月渠道明细；包括该用户所有 API Key。
- 所有金额直接取历史 quota；不按现价重新计算、不重复应用折扣。USD 美元等值明确区分充值和上游成本。
- 已有日志可能被清理，因此固定说明基于现存日志；空月显示无消费记录，不保证完整会计账单。缺失渠道保留 ID 并标记未命名/已删除。
- 管理员鉴权、单次年度查询、超时、禁用缓存、跨数据库 SQL；无需数据库迁移、不得写余额或改计费。金额使用精确十进制字符串，导出 CSV 保留精度并防公式注入。
- 覆盖用户隔离、月份边界、退款、零消费、未来年份、超 int32 汇总、分离日志库、普通用户拒绝访问；前端类型/规则/构建、实际界面验证。
